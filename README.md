A two-part micro-confession for make.fun's "Unsent: The Micro-Confession Sprint": a To: line naming who it was meant for, and the unsent message itself, one line written exactly as it was typed, with no explanation after it. The program writes it to `/output/entry.txt`, where the house judge compares it two at a time on how genuinely unsent it feels.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
